# printf와 이스케이프 시퀀스

**난이도:** ★
**문제 링크:** https://compilerun.vercel.app/problems/e8f79ef1-6487-40e9-8b69-f423801e6828

## 문제 지문

이스케이프 시퀀스를 사용해 아래 두 줄을 정확히 출력하세요. 둘째 줄은 탭 문자로 시작하며, 큰따옴표를 포함합니다.

[입력] 없음
[출력]
그가 큰 소리로 말했다.
	"여러분! 침착하세요."

## 내 오답 코드

```python
ㄹㄹㄹ
```

## 내 정답 코드 (Python)

```python
print("그가 큰 소리로 말했다.")
print("\t\"여러분! 침착하세요.\"")
```

## 모범 답안

```python
#include <stdio.h>
int main(void)
{
    printf("그가 큰 소리로 말했다.\n");
    printf("\t\"여러분! 침착하세요.\"\n");
    return 0;
}
```

## 해설

문자열 안에서 특수 문자를 표현하려면 역슬래시로 시작하는 이스케이프 시퀀스를 사용합니다.
