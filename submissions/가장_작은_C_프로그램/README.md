# 가장 작은 C 프로그램

**난이도:** ★
**문제 링크:** https://compilerun.vercel.app/problems/797d5e08-2973-4310-bbd1-21a5f2899db6

## 문제 지문

프로그램의 필수 뼈대만 갖춘, 아무것도 입력받지 않고 아무것도 출력하지 않는 프로그램을 작성하세요. 프로그램은 에러 없이 정상 종료되어야 합니다.

[입력] 없음
[출력] 없음 (아무것도 출력하지 않고 정상 종료)

## 내 오답 코드

```python
int main(void) { return 0; }d
```

## 내 정답 코드 (Python)

```python
pass
```

## 모범 답안

```python
int main(void)
{
    return 0;
}
```

## 해설

C 프로그램은 운영체제가 가장 먼저 찾는 main 함수에서 시작합니다. 아무리 작은 프로그램이라도 시작점 함수는 반드시 존재해야 합니다.
